# 🛡️ Python Domain Risk & Security Scanner

A lightweight, high-performance Python security tool to analyze domain threat posture, risk scores, SSL health, and HTTP header vulnerabilities.

Powered by the **[Domain and Risk Profiler API](https://rapidapi.com/Huebercool/api/domain-and-risk-profiler)** on RapidAPI.

---

## 🚀 Quickstart

### 1. Install Dependencies
```bash
pip install -r requirements.txt

export RAPIDAPI_KEY="your_actual_rapidapi_key_here"
python risk_scanner.py

DOS
set RAPIDAPI_KEY="your_actual_rapidapi_key_here"
python risk_scanner.py

Shell

$env:RAPIDAPI_KEY="your_actual_rapidapi_key_here"
python risk_scanner.py
